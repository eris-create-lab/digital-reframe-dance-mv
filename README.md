# Digital Reframe Dance MV

15秒前後のワンカット・ダンス動画を、映像生成を使わずにMV風へ編集するChatGPT Work / Codex向けスキルです。

元動画をデジタルリフレーミングし、全身・腰上・顔・足元・手元などのショットへ切り替えます。キャラクター、振付、再生速度、時間同期は維持します。

## できること

- 固定カメラのワンカット動画を複数カメラ風に編集
- 動きに合わせたズーム、パン、追従、アップショット
- 素材に応じて `CLEAN` / `IMPACT` / `GRAPHIC` / `FASHION` / `LIVE` を選択
- フラッシュ、軽いRGBずれ、ライト演出などを必要な箇所だけに追加
- 元動画と編集版の比較動画を任意で作成
- 解像度、fps、フレーム数、音声同期を検証

毎回同じ編集テンプレートを適用するのではなく、ダンス、背景、カメラワーク、音のアクセントを解析して編集方針を変えます。

## 守ること

- キャラクターを描き直さない
- 人物を別人化しない
- ポーズや振付を変更しない
- 存在しないカメラアングルを生成しない
- 指定がない限り、再生速度と時間軸を変更しない
- 元動画の音声と同期を維持する

## ChatGPT Workへの導入

1. [ZIPをダウンロード](https://github.com/eris-create-lab/digital-reframe-dance-mv/archive/refs/heads/main.zip)します。
2. ChatGPT WorkでZIPを添付します。
3. 「このZIPからスキルを作成してインストールして」と依頼します。
4. インストール後、編集したいダンス動画を添付してスキルを呼び出します。

## 基本的な使い方

動画を添付して、次のように依頼します。

```text
$digital-reframe-dance-mv を使って、
このワンカットのダンス動画を素材に合った演出のMVへ編集してください。
キャラクター、振付、時間同期、元のカメラ視点は維持してください。
```

### 控えめな編集

```text
カット切替は少なめにして、全身ショットを中心にしてください。
顔アップと足元アップを短く入れ、エフェクトは控えめにしてください。
```

### 強めのMV編集

```text
動きの強い箇所を優先し、素材に合うシグネチャー技法を2種類まで使ってください。
残像は使わず、人物の見やすさを優先してください。
```

### 比較動画も作る

```text
編集版を完成させた後、元動画と編集版を横並びにした比較動画も作ってください。
元動画を再生して停止し、その後に編集版を再生して停止する構成にしてください。
```

編集済みMVが標準の成果物です。比較動画は、依頼された場合だけ追加で作成します。

## 必要な環境

- Python 3
- FFmpeg / ffprobe
- OpenCV（解析や追加処理で必要な場合）

## 注意

本スキルは、元映像に存在する画角を切り抜いて編集するものです。真横、背面、別ロケーションなど、元動画に映っていない内容を生成する用途ではありません。
